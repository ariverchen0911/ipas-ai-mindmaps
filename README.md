# iPAS AI 初級雙科互動心智圖

手機與電腦入口：https://ariverchen0911.github.io/ipas-ai-mindmaps/

- 第一科：[人工智慧基礎概論](https://ariverchen0911.github.io/ipas-ai-mindmaps/subject1.html)，71 個重要觀念、200 題範疇索引。
- 第二科：[生成式 AI 應用與規劃](https://ariverchen0911.github.io/ipas-ai-mindmaps/subject2.html)，44 個重要觀念、200 題範疇索引。

適用 115 年第四次初級，考試日 2026-11-07。依官方 115.06 評鑑內容範圍，以及 114 年第四次、115 年第一至第三次初級公告試題整理。查核日 2026-11-06。

## 使用

用手機 Safari 或 Chrome 開啟上方網站，點選科目即可。支援主題與觀念展開、搜尋、易錯提醒、遮蔽自測、待複習／已熟悉標記、JSON 匯出／匯入與列印。手機為直向樹狀圖，桌面為橫向樹狀圖。

複習標記只存於當前瀏覽器，不上傳、不跨裝置自動同步。換裝置可匯出再匯入。可將網站加入手機主畫面。

各科 HTML 內嵌資料、樣式與程式，沒有外部 CDN，可下載後在支援 JavaScript 的瀏覽器離線開啟。GitHub 原始碼預覽不執行互動，請使用 Pages 網址。

## 範圍

第一科依 L111 人工智慧概念、L112 資料處理與分析、L113 機器學習、L114 鑑別式與生成式 AI 編排。第二科依 L121 No Code / Low Code、L122 應用領域與工具使用、L123 導入評估及風險管理編排。

每科保留四次試卷的完整 200 題題號與既有主題標籤索引。節點的相關題號是題幹關鍵字比對，代表提及該詞，不代表該詞即正解；未命中不代表未考。未使用中級試題。非官方教材、非官方配分、非命題預測。

官方來源：https://ipd.nat.gov.tw/ipas/certification/AIAP/downloads
